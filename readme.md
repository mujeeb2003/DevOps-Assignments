## ☁️ Azure Basic Labs

Comprehensive Azure cloud fundamentals exercises covering essential Azure services and concepts.

### Lab Coverage (Labs 1-10)
- **Azure Portal Navigation**: Resource management and dashboard customization
- **Virtual Machines**: Creation, configuration, and management
- **Storage Accounts**: Blob storage, file shares, and access policies
- **Virtual Networks**: Subnet configuration and network security groups
- **Azure Active Directory**: User management and access control
- **Azure SQL Database**: Database creation and connection management
- **App Services**: Web app deployment and scaling
- **Azure Functions**: Serverless computing implementation
- **Monitoring & Diagnostics**: Azure Monitor and Application Insights
- **Cost Management**: Resource optimization and billing analysis

### Key Learning Objectives
- Azure resource lifecycle management
- Cloud security best practices
- Scalability and availability concepts
- Cost optimization strategies
- Azure service integration

## 🏗️ Terraform Labs

Infrastructure as Code (IaC) implementations using Terraform for Azure resource provisioning.

### Lab Structure
- **Lab 02**: Basic Azure resource creation (Resource Groups, VNets, Subnets)
- **Lab 03 (Stages 1-5)**: Progressive infrastructure complexity
  - Stage 1: Variable implementation and resource parameterization
  - Stage 2: Network Security Groups and security rules
  - Stage 3: Virtual machine provisioning with networking
  - Stage 4: Output values and resource referencing
  - Stage 5: Advanced configurations and state management

### Technologies & Concepts
- **Terraform Core**: Resource blocks, providers, and state management
- **Azure Provider**: AzureRM provider configuration
- **Variables**: Input variables and local values
- **Outputs**: Resource attribute exposure
- **State Management**: Terraform state file handling
- **Resource Dependencies**: Implicit and explicit dependencies

### Key Features
- Modular infrastructure design
- Parameterized resource configurations
- State file management and versioning
- Azure resource group organization
- Network security implementation

## 🐳 Docker Lab - License Manager

A comprehensive microservices application demonstrating Docker containerization, networking, and deployment concepts.

### Features
- **Frontend**: React.js with TypeScript
- **Backend**: Node.js/Express with JWT authentication
- **Database**: MySQL with Sequelize ORM
- **Health Monitoring**: Real-time system status dashboard
- **Email Automation**: SMTP integration with Nodemailer

### Architecture
- Multi-container Docker setup with custom networking
- Volume persistence for database storage
- Docker Hub image deployment
- Inter-service communication using container names

## 🚀 Getting Started

Each lab contains detailed documentation and implementation files:

### Prerequisites
- Azure account with active subscription
- Docker Desktop installed
- Terraform CLI (v1.0+)
- Git installed
- Node.js (v16+) for Docker lab

### Quick Start
1. Clone the repository
2. Navigate to specific lab directories
3. Follow individual README files for setup instructions
4. Review architecture diagrams and deployment steps

### Lab-Specific Setup
- **Azure Labs**: Use Azure Portal or Azure CLI
- **Terraform Labs**: Initialize with `terraform init` and plan with `terraform plan`
- **Docker Lab**: Use `docker-compose up` for multi-container deployment
- **DevOps Project**: Follow Jenkins pipeline setup guide
